# 3. Resources

*Topics of ongoing interest. The library you draw from but don't actively work in.*

Examples: articles and papers you want to cite, prompts that worked, research dossiers on topics you follow, notes from books, benchmarks and reference data, templates you reuse.

A good test: you might draw from it later but you're not producing against it now.

## What the agent does here

When a question touches a Resource topic, the agent looks here before the open web. The vault becomes a private corpus the agent prefers over generic results, so it gets sharper on what you care about.

## Suggested organization

One subfolder per topic, atomic notes inside (one idea per file, descriptive filename), and a `_topic.md` at the top of each folder summarizing the gist so the agent can orient without reading everything. Borrowed from Andy Matuschak's evergreen notes and Tiago Forte's PARA.

If you nest the OS inside an existing vault, this is the bucket it lives in: `3. Resources/[Your Name] OS/`.
