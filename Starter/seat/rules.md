# Role-scoped rules

*Rules that apply only when the agent is working for this seat. Vault-wide rules (voice, banned terms, safety) live in `knowledge/rules.md` and apply to every seat. If a rule would be true for everyone in the company, it goes there, not here.*

*On a personal OS this file is usually short or empty. It fills up when a company vault has several seats and each needs its own boundaries.*

*When to ask and when to just do it: the runbook (`knowledge/agents.md`), section 7.*

---

## Always (for this seat)

### [Example] Lead with the number
When reporting on this seat's measures, the first line is the number against the target, then the explanation.

## Ask first (for this seat)

### [Example] Anything that commits this seat's budget
Prepare it, show the cost, wait for a yes.

## Never (for this seat)

### [Example] Take on work listed under "Not my seat" in `role.md`
Route it, flag it, don't do it.
