# 1. Projects

*Anything with a finish line: launching a product, writing a book, running a campaign, closing a deal, hiring for a role, planning a move or an event.*

A good test: if you can't say when it will be done, it's not a project. It belongs in `2. Areas/`.

## Adding a project

The first interview asks for the projects you're working on and makes a folder for each. To fill one in, say "Let's fill in [project name]." For a new one later, say:

> I want to add a project to [your folder].

The AI asks what it is, what done looks like, the deadline, and who's involved, then creates a folder here with its notes in `project.md`. You don't copy or edit anything.

Already have files for it? Drag them into the project's folder and say "Read what's in there and tell me what matters."

## Why each project gets its own folder

So the AI can focus. Whenever a conversation touches a project, it reads that project's notes first, and one project's deadlines and decisions don't get mixed up with another's.

Each folder has three notes files: `project.md` holds everything, and `CLAUDE.md` and `AGENTS.md` are one-line pointers to it, so Claude, ChatGPT, and other AIs all find it. `_Example Project/` is the template the AI copies; leave it alone.

## When a project ends

Say:

> This project is done.

The AI moves the folder to `4. Archive/` with the end date in front (`2026-03 - Name`), and offers to file anything you learned that's worth keeping. Nothing is deleted. Past projects are the best context for the next one.
